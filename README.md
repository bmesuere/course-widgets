# Course Widgets

A collection of interactive widgets and demos designed for computer science and data science lectures at Ghent University.

These widgets are built with modern web technologies (HTML, CSS, JavaScript) and are designed to be used during live lectures to demonstrate complex concepts through interaction.

## 🚀 Live Demo

The project is automatically deployed to GitHub Pages and can be accessed here:
👉 **[https://bmesuere.github.io/course-widgets](https://bmesuere.github.io/course-widgets)**

## 📦 Modules

### Data Visualisation
Explore core concepts in data visualization:
- **Anscombe's Quartet**: Why summary statistics alone can be misleading.
- **Axis Manipulation**: Demonstrating the "Lie Factor" through truncated and exaggerated scales.
- **Preattentive Processing**: Understanding visual search efficiency and pop-out effects.
- **The 15 Game**: A numerical representation puzzle.

## 🛠 Development

The widgets are self-contained HTML files located in module-specific directories (e.g., `datavisualisation/`).

They use:
- **Tailwind CSS**: For rapid, consistent styling.
- **Vanilla JavaScript/Canvas**: For high-performance interactive visualizations.
- **GitHub Actions**: For automated deployment to GitHub Pages.

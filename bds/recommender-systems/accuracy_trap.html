The Lesson

Model A had the "better" error score because it played it safe. It minimized mistakes but missed the magic. Model B had a worse score because it took a risk (and missed on the News item), but it successfully found the localized content the user actually wanted.

Minimizing RMSE ≠ Maximizing User Happiness.
